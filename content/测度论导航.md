本专题共有 122 张词条卡片，以定义、命题、例子、反例与证明组成相互链接的测度论百科。可以从[测度（Measure）](词条/Measure.md)开始，也可以使用[中英术语索引](词条索引.md)按名称查找。

核心来源为 Bass《Real Analysis for Graduate Students》前十三章、Folland《Real Analysis》第二版前三章，以及 Chen Wang 的《Notes on Real Analysis》。Lp 理论来自个人实分析笔记；概率相关词条依据个人 Lévy 过程笔记作补充。具体章节对应见[范围与来源](范围与来源.md)。

## 阅读路径

- 从集合到测度：[σ-代数（Sigma-algebra）](词条/Sigma-algebra.md) → [测度（Measure）](词条/Measure.md) → [外测度（Outer measure）](词条/Outer-measure.md) → [Carathéodory 扩张定理（Carathéodory extension theorem）](词条/Caratheodory-extension-theorem.md) → [Lebesgue 测度（Lebesgue measure）](词条/Lebesgue-measure.md)。
- 从函数到积分极限：[可测函数（Measurable function）](词条/Measurable-function.md) → [简单函数（Simple function）](词条/Simple-function.md) → [Lebesgue 积分（Lebesgue integral）](词条/Lebesgue-integral.md) → [单调收敛定理（Monotone convergence theorem）](词条/Monotone-convergence-theorem.md) → [Fatou 引理（Fatou lemma）](词条/Fatou-lemma.md) → [控制收敛定理（Dominated convergence theorem）](词条/Dominated-convergence-theorem.md)。
- 从积空间到换序：[乘积 σ-代数（Product sigma-algebra）](词条/Product-sigma-algebra.md) → [乘积测度（Product measure）](词条/Product-measure.md) → [Tonelli 定理（Tonelli theorem）](词条/Tonelli-theorem.md) → [Fubini 定理（Fubini theorem）](词条/Fubini-theorem.md) → [积分换元公式（Change of variables formula）](词条/Change-of-variables.md)。
- 从符号到密度：[有符号测度（Signed measure）](词条/Signed-measure.md) → [Hahn 分解定理（Hahn decomposition theorem）](词条/Hahn-decomposition-theorem.md) → [Jordan 分解定理（Jordan decomposition theorem）](词条/Jordan-decomposition-theorem.md) → [Radon–Nikodym 定理（Radon–Nikodym theorem）](词条/Radon-Nikodym-theorem.md) → [Lebesgue 分解定理（Lebesgue decomposition theorem）](词条/Lebesgue-decomposition-theorem.md)。
- 从平均到微分：[Vitali 覆盖引理（Vitali covering lemma）](词条/Vitali-covering-lemma.md) → [Hardy–Littlewood 极大不等式（Hardy–Littlewood maximal inequality）](词条/Maximal-inequality.md) → [Lebesgue 微分定理（Lebesgue differentiation theorem）](词条/Lebesgue-differentiation-theorem.md) → [有界变差函数（Functions of bounded variation）](词条/Bounded-variation.md) → [绝对连续函数（Absolutely continuous functions）](词条/Absolute-continuity-of-functions.md)。
- 从积分到函数空间：[Lebesgue 空间（Lp space）](词条/Lp-space.md) → [Hölder 不等式（Hölder inequality）](词条/Holder-inequality.md) → [Lp 完备性（Completeness of Lp）](词条/Lp-completeness.md) → [Lp 中的稠密逼近（Density in Lp）](词条/Lp-density.md) → [Lp 对偶定理（Duality of Lp）](词条/Lp-duality.md)。
- 概率中的测度语言：[概率测度（Probability measure）](词条/Probability-measure.md) → [推前测度（Pushforward measure）](词条/Pushforward-measure.md) → [随机变量的分布（Law of a random variable）](词条/Law-of-a-random-variable.md) → [条件期望（Conditional expectation）](词条/Conditional-expectation.md) → [Lévy 测度（Lévy measure）](词条/Levy-measure.md)。
